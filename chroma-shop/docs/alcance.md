# Alcance y tecnologías
Chroma Shop es una tienda académica de maquillaje con catálogo, diagnóstico cromático, equivalencias y asesor por ocasión, carrito persistente, pedidos contra entrega, seguimiento, favoritos, foto de perfil y mapa de puntos demo. El administrador crea, edita y retira productos (borrado lógico para conservar historial) y avanza pedidos. Ionic React, TypeScript, Context, Hooks, Capacitor Camera/Geolocation/Haptics, localStorage, Supabase Auth/PostgreSQL/RLS/Storage/Realtime, FastAPI y Leaflet. El motor cromático reutiliza reglas y datos de Chroma original. No se ofrecen garantías de coincidencia de color en piel, pagos reales ni entregas reales. La base comercial es independiente. La transacción SQL bloquea filas de inventario y calcula precios en servidor. Validación integrada y compilación pendientes.
